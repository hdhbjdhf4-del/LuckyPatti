# Zoo Roulette V2 — Android project

Offline virtual-coin roulette demo for Android 8.0+ (minSdk 26).
Includes Monkey, Rabbit, Lion, Panda, Shark, Bird, Swallow, Pigeon, Peacock and Eagle; betting board, 20-second timer, random result, history, rebet and saved virtual coins.
No internet permission, real-money betting, deposits or cash-out.

GitHub Actions builds a debug APK. Open Actions and download the Zoo-Roulette-V2-debug-apk artifact after the run succeeds.
The UI is a 2D casino-inspired interface with a roulette animation, not a full 3D game engine.
